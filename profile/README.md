# Corpus Adequacy

Corpus Adequacy is a deterministic, offline-first tool for a narrow testing
question: can an implementation remove an author-declared rule and still
reproduce a published conformance corpus's declared observations?

- [Tool and source](https://github.com/corpus-adequacy/corpus-adequacy)
- [Rendered documentation and measurements](https://corpus-adequacy.github.io/corpus-adequacy/)
- [Corpus intake](https://github.com/corpus-adequacy/corpus-adequacy/issues/new?template=add-corpus.yml)
- [Usage questions](https://github.com/corpus-adequacy/corpus-adequacy/discussions)
- [Private vulnerability reporting](https://github.com/corpus-adequacy/corpus-adequacy/security/advisories/new)

The tool keeps observations, rule inventory, exclusions, and evidence identity
in explicitly separated reports and projections. It does not infer a complete
rule inventory, certify a corpus or implementation, or provide a general
security score.
